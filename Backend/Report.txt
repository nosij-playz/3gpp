All traffic mapped to the same 5G QoS Flow receives the same forwarding treatment, including RLC configuration, rate shaping policy, queue management policy, and scheduling policy [Source: 23501-j60.docx, 23501-k10.docx]. Separate 5G QoS Flows are required to provide different QoS forwarding treatment [Source: 23501-j60.docx, 23501-k10.docx, 23501-j50.docx].

        *   The AMF is a network function within the Control Plane of the service-based 5G architecture [Source: 23501-k00.docx].

        *   The AMF provides the 5G-AN node with weight factors for each TNL association, requests the addition or removal of TNL associations, and indicates to the 5G-AN node which TNL associations are used for UE-associated versus non-UE associated signalling [Source: 23501-j70.docx].
        
        **Interaction with the gNB**
        *   **Security Context Establishment:** When establishing the AS security context in the gNB, the AMF sends the complete UE 5G security capabilities (all bits for every capability defined in TS 24.501 received in NAS signalling) to the gNB [Source: 38300-he0.docx].
        *   **Handover and Security Verification:**
            *   The gNB/ng-eNB sends a Handover Required message to the AMF, which includes the UE's identity [Source: 33501-fj0.docx, 33501-j40.doc].
            *   In a Path-Switch message, the target gNB/ng-eNB sends the UE's 5G security capabilities (received from the source gNB/ng-eNB) to the AMF [Source: 33501-j60.docx].
            *   The AMF verifies if these received capabilities match the UE's 5G security capabilities stored locally [Source: 33501-j60.docx, 33501-j40.doc].
            *   If a mismatch occurs, the AMF sends its locally stored 5G security capabilities to the target gNB/ng-eNB via a Path-Switch Acknowledge message; the AMF may also raise an alarm or log the event [Source: 33501-j40.doc].
        *   **Security Key Association:** The target gNB/ng-eNB associates the NCC value received from the AMF with the KgNB to derive the 5G AS security context [Source: 33501-fk0.docx].
